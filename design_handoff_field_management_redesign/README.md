# Handoff: 현장관리 앱 디자인 리뉴얼

## Overview
"현장관리 시스템" 모바일 웹앱의 전체 UI 리디자인. 기존 GitHub 저장소(`slkamg0-ai/Building-Field-Management`)의 화면 구조와 데이터 모델을 참고해, "Industry" 디자인 시스템(스틸블루 블루프린트 톤)을 적용했다. 로그인, 대시보드, 일일 작업일보(노무/장비/자재/경비/외주), 근로자 관리(+출퇴근), 기성관리(계약품목/시공수량/청구서/투입명세서/수지분석), 건의사항, 사용자 관리 화면을 포함한다.

## About the Design Files
이 폴더의 `현장관리앱.dc.html`은 **디자인 레퍼런스**로 만들어진 HTML 프로토타입이다. 실제 프로덕션 코드로 그대로 복사해 붙이는 것이 아니라, 기존 Next.js/React 코드베이스(`slkamg0-ai/Building-Field-Management`, `src/app/*`)의 기존 패턴과 라이브러리를 사용해 이 디자인을 **재구현**해야 한다. 상태 관리 로직(더미 데이터, 폼 처리)은 참고용이며, 실제 API/DB 연동은 기존 코드베이스의 방식을 따른다.

## Fidelity
**고정밀도(High-fidelity)**: 색상, 타이포그래피, 레이아웃, 여백, 인터랙션이 최종 확정된 상태다. 개발자는 기존 코드베이스의 컴포넌트/스타일 체계를 사용해 픽셀 단위로 동일하게 재현해야 한다.

- **텍스트 기본**: `#1d1f20`
- **텍스트 보조**: `rgba(29,31,32,0.5~0.6)`
- **primary(강조/버튼/활성탭)**: `#5980a6` (steel blue)
- **primary hover/text 강조**: `#416180`
- **경고 배지 보더/텍스트**: `#5980a6` / `#416180`

- **간격 스케일**: 6 / 8 / 10 / 12 / 14 / 16 / 22px 위주

## Screens / Views

### 1. 로그인 (Login)
- 이름 입력 + PIN 8자리 도트 인디케이터 + 숫자 키패드(1-9,0,C,⌫) 입력 방식 (기존 저장소의 PIN 로그인 로직 유지)
- 데모용 ADMIN/WORKER 역할 전환 토글 포함 (실제 구현에서는 서버가 역할을 반환하므로 제거)
- CTA: "접속하기" — steel blue 배경, 비활성 시 반투명

### 2. 대시보드
- 상단: 현장명 + 원청사명 배지
- 이번달 누적 지출 카드: 진행률 바(도급액 대비 %), 코너 마커 장식
- 노무비/장비비/외주비/경비 2x2 그리드 카드
- 오늘 투입 현황 합계 카드
- 오늘 작업내용 + 현장 사진 3장 슬롯

### 3. 일일 작업일보
- 노무/장비/자재/경비/외주 5개 서브탭 (탭 리스트는 배열 기반으로 렌더링할 것 — 반복되는 조건 분기 블록을 여러 개 나열하는 방식은 지양하고 배열 map/반복 렌더링 권장)
- 각 탭: 항목 리스트(이름/단가/수량/합계) + "+추가" 폼(인라인 확장형)
- 노무: 근로자 미등록/서류미비 경고 배지 (근로자 관리 데이터와 연동)
- 장비: 원청직영/당사투입 구분, 서류 확인필요 경고
- 하단: 작업내용 텍스트 + 사진 3슬롯 + 오늘 총 투입비용 합계

### 4. 근로자 관리
- 근로자 목록 / 출퇴근 현황 서브탭
- 근로자 등록 폼: 이름/연락처/소속업체/직종/생년월일/은행/계좌/안전교육일/안전교육번호/기초안전보건교육 체크
- 서류완비/서류미비/검토필요/확인필요 상태 배지
- 중복 근로자 병합 기능(기준 근로자 선택 + 병합 대상 다중 체크)
- 출퇴근: 날짜별 리스트, 관리자 확인/반려

### 5. 기성관리
- 계약품목/시공수량/기성청구서/투입명세서/수지분석 5개 서브탭
- 계약품목: 공종 그룹 → 품목별 규격/단위/단가/금액/누적/이번달/잔량
- 시공수량: 품목 선택 + 수량 입력, 오늘 입력 리스트
- 청구서: 이번달/누적/전월 기성고, 품목별 청구액, 원청 제출/지급확정 버튼(ADMIN)
- 투입명세서: 노무 일자별 공수 테이블, 자재/경비/외주 집계
- 수지분석: 청구액 vs 실투입원가 vs 손익(월/누적)

### 6. 건의사항
- 카테고리(요구사항/버그/기타) + 상태(대기/진행중/완료) 필터
- 작성 폼(인라인), 카드형 리스트, ADMIN만 상태 변경/삭제 가능

### 7. 사용자 관리 (ADMIN)
- 신규 접속자 등록(이름/PIN/역할)
- 사용자 목록: 역할 배지, 활성/비활성 토글, PIN 변경(인라인), 삭제

## Interactions & Behavior
- 하단 탭바: 대시보드/일보/근로자(ADMIN만)/기성/더보기(오버플로 시트: 건의사항/출퇴근체크/사용자관리(ADMIN)/로그아웃)
- 모든 "+추가" 폼은 인라인 확장형 (모달 아님)
- 경고 배지(서류 미비 등)는 노무/장비 리스트에서 실시간 계산되어 표시
- 화면 전환은 즉시(트랜지션 없음), 모바일 세로 프레임(412px 폭) 기준
