# 🛰️ SmartField RTK (독립형 GPS 측량 및 측설 모바일 앱)

> **MG(머신가이던스) 구축 전 선행작업용 GPS 자작측량기 구동 전용 모바일 앱**  
> 스마트폰에서 블루투스/USB로 자작 GNSS 수신기(u-blox ZED-F9P, Unicore UM980 등)에 연결하여 국토지리정보원 NTRIP 보정을 받고, 음성 명령으로 수치측량과 3D 측설, 캐드 도면(DXF) 대조 및 현장 캘리브레이션을 수행합니다.

---

## 📱 5대 핵심 구현 사양

1. **스마트폰 최적화 구동 (Mobile-First)**
   - **야외 시인성 극대화**: 직사광선 아래에서도 선명한 고대비 다크 HUD 테마.
   - **Wakelock 화면 꺼짐 방지**: 측량 폴대를 잡고 이동 중에도 화면 상시 유지.
   - **장갑 터치 대응**: 직경 112px의 초대형 원터치 측정 버튼.
   - **무선 통신 지원**: Web Bluetooth(BLE), USB OTG 시리얼(115200bps), 가상 필드 시뮬레이션 탑재.

2. **초고속 접속, 측량, 측설 및 성과 도출**
   - **1초 단발 / 3~5초 에포크 평균 측정**: 다중 에포크 실시간 오차 누적 평균화.
   - **자동 점번 증가**: `PT001`, `PT002`... 자동 카운팅 및 폴대고(2.0m) 자동 보정.
   - **3D 불스아이(Bullseye) 측설 HUD**: 목표점 방향 화살표, 전후/좌우 실시간 거리, **절토(CUT) / 성토(FILL)** 잔차 표기.
   - **근접 가변 비프음 (Web Audio API)**: 목표점 1m 진입 시 거리에 비례하여 비프음 가속, 3cm 허용오차 안착 시 고주파 고정음 출력.
   - **원클릭 다중 내보내기**:
     - **CSV**: 한글 엑셀 깨짐 없는 UTF-8 BOM 서식.
     - **DXF**: AutoCAD에서 바로 열리는 측점 및 텍스트 도면 파일.
     - **MG 연계 JSON**: 굴착기 머신가이던스 제어 캐빈 HUD로 전송 가능한 기준점 포맷.
     - **카카오톡 간편 복사**: 현장 관리자/단톡방 즉시 보고용 텍스트 복사.

3. **음성인식(STT) 및 음성피드백(TTS) 핸즈프리**
   - 2m 폴대와 수평 기포관을 양손으로 잡은 상태에서 스마트폰 터치 없이 음성으로 조작:
     - 🗣️ **"측정"** 또는 **"기록"**, **"찍어"**: 현재 좌표 에포크 측정 및 성과 저장.
     - 🗣️ **"취소"**: 직전 측점 무효화.
     - 🗣️ **"코드 [맨홀/도로/TBM]"**: 지목 코드 음성 전환.
     - 🗣️ **"이름 [1번]"**: 측점명 음성 변경.
   - 🔊 **음성 피드백**: *"RTK 고정, PT001 저장 완료. 오차 1.1센티."*, *"전방 40센티, 우측 15센티, 성토 5센티"* 실시간 안내.

4. **상용 측량기급 필수 기능 (NTRIP, 좌표계, 지오이드, 캘리브레이션)**
   - **국토지리정보원(NGII) Caster 원터치 연동**: `rtk.ngii.go.kr:2101` (`VRS-RTCM32`, `VRS-RTCM31`, `RTK-RTCM32` 프리셋).
   - **NMEA $GGA 업로드 & RTCM3 수신기 주입**: 가상기준점(VRS) 자동 스트리밍.
   - **한국 표준 TM 투영 좌표계**: EPSG:5186(중부원점 2010), EPSG:5185(서부), EPSG:5187(동부), EPSG:5188, EPSG:5179(UTM-K), EPSG:5174(Bessel).
   - **KNGeoid18 지오이드 모델**: 타원체고($h$)에서 지오이드고($N$)와 폴대고를 차감하여 국가 표준 표고($H$, 해발고도) 즉시 계산.
   - **현장 캘리브레이션 (점합치 / 로컬라이제이션)**: TBM 2점 이상 대조로 2D 헬머트 4변수($\Delta X, \Delta Y, \theta, Scale$) 및 표고 보정치($\Delta Z$) 산출.

5. **CAD 도면(DWG / DXF) 및 지도 연동**
   - **DWG / DXF 듀얼 지원**: AutoCAD 바이너리 원본 **`.dwg`** 파일 및 텍스트 **`.dxf`** 파일 모두 모바일에서 직접 열람 및 파싱 지원.
   - **WebAssembly(WASM) LibreDWG 엔진 탑재**: 복잡한 서버 변환 없이 스마트폰 브라우저/앱 로컬 메모리에서 즉시 고속 벡터 파싱.
   - **고속 캔버스 벡터 렌더러**: 선(LINE), 폴리라인(POLYLINE), 원/맨홀(CIRCLE), 텍스트(TEXT), 지시선 레이어별 가시성 필터링.
   - **실시간 RTK 커서**: 오차 반경 동심원, 헤딩 방위 화살표, 십자선 커서 추적.
   - **원터치 스냅 측설**: 도면 위 맨홀 중심이나 변곡점을 터치하면 즉시 측설 목표점으로 등록.
   - **기본 도면 탑재**: 프로젝트 내 실제 도면인 `Osu_plan_2_simple.dxf` 오수관로선/맨홀이 기본 로드되어 시험 가능.

## 🚀 빠른 시작 가이드

### 1) PC 및 스마트폰 브라우저에서 실행 (PWA 모드)
```bash
cd gps-survey-app
npm run dev
```
- 브라우저에 표시되는 로컬 IP 주소(예: `http://192.168.0.x:5174`)로 스마트폰 크롬에서 접속하면 즉시 모바일 측량기로 구동됩니다.
- 초기 기동 시 **가상 필드 시뮬레이션(u-blox ZED-F9P 5Hz)**이 자동 동작하여 실내에서도 모든 측량/측설/음성 기능을 바로 시험해 볼 수 있습니다.

### 2) 상용 안드로이드 앱(APK) 패키징 (Capacitor)
```bash
# Capacitor CLI 설치 및 초기화
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "SmartField RTK" "com.field.smartrtk" --web-dir dist
npm run build
npx cap add android
npx cap open android
```
- Android Studio에서 `Build APK`를 누르면 즉시 스마트폰 설치용 `.apk` 파일이 생성됩니다.
